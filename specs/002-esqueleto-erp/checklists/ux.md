# Checklist Nielsen y accesibilidad F2

- [x] Visibilidad del estado: login, cambio de clave y acciones admin muestran éxito o error.
- [x] Coincidencia con el mundo real: interfaz en español y vocabulario notarial.
- [x] Control y libertad: cambio de clave y acciones admin ofrecen cancelar o volver.
- [x] Consistencia: controles equivalentes conservan ubicación y estilo.
- [x] Prevención de errores: campos obligatorios se validan y desactivar/reactivar pide confirmación.
- [x] Reconocer antes que recordar: navegación y rol visible.
- [x] Flexibilidad: listado admin permite búsqueda y filtros básicos.
- [x] Diseño minimalista: solo se muestran controles del flujo F2.
- [x] Recuperación: errores explican qué revisar sin datos personales.
- [x] Ayuda: login y cambio de clave incluyen ayuda breve.
- [x] Etiquetas accesibles en todos los campos propios.
- [x] Navegación por teclado y foco visible.
- [x] Contraste suficiente en controles y mensajes.
- [x] Sin llamadas CDN o recursos externos en runtime.
