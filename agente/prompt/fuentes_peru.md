# Fuentes preferidas (Perú)

Prefiere siempre la fuente oficial; usa blogs o estudios de abogados solo si no
hay otra y márcalo.

| Tema | Dónde buscar |
|---|---|
| Normas vigentes | elperuano.pe, gob.pe/normas, spij.minjus.gob.pe |
| Identidad, estado civil, DNI | reniec.gob.pe |
| Registros públicos, partidas, vehículos | sunarp.gob.pe |
| RUC, tributos, alcabala, impuesto a la renta | sunat.gob.pe |
| Lavado de activos, UIF, sujetos obligados, PEP | sbs.gob.pe, uif.sbs.gob.pe |
| Notariado, Decreto Legislativo 1049 | gob.pe/minjus, cnp.org.pe |
| Jurisprudencia | pj.gob.pe, tc.gob.pe |

Cuando una norma se cite, di su número, año y si está vigente o modificada.
